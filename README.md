# תוכניות בכיס

**מדפיסים. משחקים. נהנים.**

אתר של תוכניות ופעילויות מוכנות להדפסה: למשפחה, לחברים, לעבודה, לשבתות ולחגים, לימי הולדת, לאירועים ולילדים.
המשתמש בוחר תוכנית, קורא הסבר קצר, מוריד PDF, מדפיס ומתחיל לשחק.

---

## מה יש באתר

- **עמוד בית**: כותרת, כפתור "בואו למצוא פעילות", 8 קטגוריות, "הפעילויות הפופולריות ביותר" ו"התווספו לאחרונה".
- **8 קטגוריות**, כל אחת עם עמוד משלה וסינון.
- **חיפוש וסינון שעובדים**: לפי שם ומילות מפתח (מבין גם "למשפחה" ו"בשבת"), קטגוריה, מספר משתתפים, משך ורמת קושי. הסינון נשמר בכתובת, כך שאפשר לשלוח קישור לחיפוש.
- **עמוד לכל תוכנית**: איור, תיאור, משתתפים, משך, גילאים, רמת קושי, ציוד, הכנה מראש, הוראות, טיפים, תוכן הקובץ, כפתורי הורדה והדפסה ותצוגה מקדימה של כל הדפים.
- **12 תוכניות מלאות** עם תוכן אמיתי ו-**12 קובצי PDF** בתיקייה `public/pdfs`.
- **מוכן לגוגל**: כל עמוד נבנה מראש כ-HTML מלא, עם כותרת ותיאור, נתונים מובנים (schema.org), מפת אתר (`sitemap.xml`), `robots.txt` ותמונת שיתוף לווטסאפ ולפייסבוק לכל תוכנית.

## מערכת ההדפסה

- קובצי PDF אמיתיים עם טקסט (לא צילום מסך), בעברית מימין לשמאל, בגודל A4.
- שוליים של 12 מ"מ, שמתאימים לכל מדפסת ביתית.
- עיצוב בשחור-לבן ובקווים דקים, שחוסך בדיו.
- כרטיסים מסודרים ברשת עם קווי גזירה מקווקווים.
- מספרי עמודים ("עמוד 2 מתוך 5") בכל דף.
- **בדיקה אוטומטית**: בכל יצירה של קובצי PDF, הסקריפט בודק שאף דף, כרטיס או טופס לא גולש או נחתך. אם משהו נחתך, הבנייה נעצרת ומציגה איפה הבעיה.

## איך מפעילים את האתר במחשב

צריך להתקין פעם אחת את [Node.js](https://nodejs.org) (גרסה 20 ומעלה).

```bash
npm install      # פעם אחת בלבד
npm run dev      # פותח את האתר לעריכה בכתובת שמופיעה במסך
```

## איך מוסיפים תוכנית חדשה

1. בתיקייה `src/data/programs` מעתיקים קובץ קיים שדומה לתוכנית החדשה, ונותנים לו שם חדש באנגלית, למשל `pizza-quiz.ts`.
2. ממלאים את הפרטים: `id` (אותו שם באנגלית), שם, תיאורים, קטגוריות, משתתפים, משך, גילאים, ציוד, הכנה, הוראות, טיפים, מילות מפתח, ואת `sections` (מה יודפס).
3. משנים את `pdfFile` ל-`pdfs/pizza-quiz.pdf` ואת `image` ל-`images/programs/pizza-quiz.svg`.
4. שמים תמונה בתיקייה `public/images/programs` (אפשר גם `.jpg` או `.png`, רק לעדכן את הסיומת ב-`image`).
5. בקובץ `src/data/programs/index.ts` מוסיפים שורת `import` ומוסיפים את התוכנית לרשימה.

זהו. העמוד, החיפוש, הקטגוריות, מפת האתר וקובץ ה-PDF נוצרים לבד.

### סוגי עמודים שאפשר להכניס ל-PDF (`sections`)

| סוג | מה זה | דוגמה |

| `quiz` | שאלות ותשובות למנחה, בסבבים | חידון ידע כללי |
| `answerSheet` | דף תשובות לקבוצה עם שורות ממוספרות | חידון ידע כללי |
| `form` | טופס למילוי. 1, 2 או 4 בדף | חידון יום הולדת, מי מכיר את מי |
| `scoreboard` | לוח ניקוד | משימות מצחיקות |
| `table` | טבלה | ציד אוצר |
| `certificate` | תעודה, 2 בדף | ציד אוצר |

## איך בונים את האתר לגרסה שעולה לאינטרנט

```bash
npm run build:all
```

הפקודה בונה את כל העמודים, יוצרת את קובצי ה-PDF ותמונות השיתוף (משתמשת ב-Chrome או ב-Edge שמותקנים במחשב), ובודקת שאין קישורים שבורים. התוצאה נמצאת בתיקייה `dist`, ואפשר להעלות אותה לכל אחסון של אתרים סטטיים.

### פרסום אוטומטי ב-GitHub Pages (חינם)

בפרויקט יש קובץ `.github/workflows/deploy.yml`. אחרי שמעלים את הפרויקט ל-GitHub ומפעילים את Pages (Settings → Pages → Source: GitHub Actions), כל שינוי שנדחף לענף `main` נבנה ומתפרסם לבד, כולל יצירת קובצי ה-PDF.

### כתובת האתר

הכתובת מוגדרת בקובץ `site.config.json`:

- `siteUrl` ו-`basePath`: כרגע `https://luach-sport.github.io` ו-`/tochniot-bakis/`.
- כשתקנו כתובת משלכם (למשל `tochniot.co.il`), משנים ל-`"siteUrl": "https://tochniot.co.il"` ו-`"basePath": "/"`, ומעדכנים גם את `printDomain`. כל הקישורים, מפת האתר וקובצי ה-PDF מתעדכנים לבד.

### אחרי הפרסום: רישום בגוגל

1. נכנסים ל-[Google Search Console](https://search.google.com/search-console) ומוסיפים את כתובת האתר.
2. בתפריט Sitemaps מגישים את הכתובת `sitemap.xml`.

## פקודות

| פקודה | מה היא עושה |
| --- | --- |
| `npm run dev` | אתר לעריכה, מתעדכן בזמן אמת |
| `npm run build` | בניית כל העמודים |
| `npm run pdf` | יצירת קובצי PDF ותמונות שיתוף (אחרי build) |
| `npm run check` | בדיקת קישורים, קבצים ותגיות |
| `npm run build:all` | הכול ביחד |
| `node scripts/static-server.mjs` | צפייה באתר הבנוי |

```
  images/                 איורים
  og/                     תמונות שיתוף
scripts/                  בנייה, יצירת PDF ובדיקות
```
